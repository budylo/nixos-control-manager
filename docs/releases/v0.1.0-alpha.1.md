# Nix Control Manager 0.1.0-alpha.1

This is the first public prerelease of Nix Control Manager: a local graphical
control center that preserves NixOS's declarative model while hiding routine
Nix syntax behind typed controls, exact previews and explicit confirmation.

## Highlights

- 135 curated package choices, popular/category filters and eight additive
  presets;
- typed system settings with dependency checks and effective-value provenance;
- NixOS and Home Manager managed modules with portable JSON profile exchange;
- disposable Nix evaluation/build previews and opt-in, capability-separated
  system helper modes;
- timed test activation, exact tested-output switch and journal-bound rollback;
- a simple pinned flake installation, visible GUI version and read-only
  `ncm doctor` command;
- 200+ Python tests, JavaScript tests, pinned-nixpkgs checks and six booted
  NixOS VM scenarios in the release gate.

## Important alpha boundary

The supported public path is x86_64 NixOS with a flake configuration. Install
the graphical client first; it is read-only by default. The optional
`live-read-only` helper is the recommended first helper mode. Higher-authority
helper modes remain experimental and must be enabled explicitly.

Home Manager activation, driver management, the service-focused page, Plasma
Manager, automatic updates and multi-host adaptation are not included.

Follow [the installation guide](../installation.md) and keep an independently
bootable previous NixOS generation.
